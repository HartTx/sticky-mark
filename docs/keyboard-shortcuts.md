# Sticky Mark keyboard shortcuts

All shortcuts use **Control + Option** (⌃⌥) plus one more key. They work in any app, as long as Hammerspoon is running.

## Shortcuts

| Shortcut | Symbols | Action |
| --- | --- | --- |
| Control + Option + Down Arrow | ⌃⌥↓ | Move the flag down one step (28 pixels). Hold to keep moving. |
| Control + Option + Up Arrow | ⌃⌥↑ | Move the flag up one step (28 pixels). Hold to keep moving. |
| Control + Option + F | ⌃⌥F | Hide the flag. If it's hidden, show it next to the mouse pointer. |
| Control + Option + C | ⌃⌥C | Change the color: pink → blue → yellow → green → pink. |
| Control + Option + 1 | ⌃⌥1 | Make the flag pink. |
| Control + Option + 2 | ⌃⌥2 | Make the flag blue. |
| Control + Option + 3 | ⌃⌥3 | Make the flag yellow. |
| Control + Option + 4 | ⌃⌥4 | Make the flag green. |
| Control + Option + R | ⌃⌥R | Turn the flag 90 degrees clockwise: left → up → right → down → left. |
| Control + Option + E | ⌃⌥E | Turn the flag 90 degrees counterclockwise: left → down → right → up → left. |

## Mouse actions

| Action | Result |
| --- | --- |
| Click and drag the flag | Move the flag anywhere on the screen. |

## Tips

- **Find a lost flag:** Press ⌃⌥F twice. The first press hides it; the second brings it back next to your mouse pointer.
- **Point at a column instead of a row:** Press ⌃⌥E once to point the flag down, then drag it above the column.
- **Remember which rotate key is which:** E is to the left of R, and ⌃⌥E turns the flag the other way (to the left).
- **Mark two things at once:** Sticky Mark has one flag. To add more, see [Configuration](configuration.md).

## Use with a Stream Deck

Every shortcut can go on its own Stream Deck button. A good layout is one button per color, plus buttons for down, up, and hide.

1. Open the **Stream Deck** app.
2. In the actions list on the right, open **System**, then drag **Hotkey** onto an empty button.
3. Click the **Hotkey** field, then press the shortcut on your keyboard. For example, press ⌃⌥1 for pink.
4. In the **Title** field, type a label, such as `Pink`. To make the button match, set a background color that matches the flag.
5. Repeat for each button.

The number keys are the ones above the letters, not the numeric keypad.

To change these shortcuts, see [Change the keyboard shortcuts](configuration.md#change-the-keyboard-shortcuts).
